# Fozle Rabbi — Portfolio Website

A modern, responsive portfolio website showcasing my work as a Senior Software Engineer with 5.5+ years of experience in Flutter, Android Native, Full-Stack development, and Agentic AI workflows.

🌐 **Live Site:** [fozlerabbi321.github.io](https://fozlerabbi321.github.io)

---

## 🌟 Features

- **Modern Design**: Dark theme with vibrant purple/blue gradients and glassmorphism effects
- **Fully Responsive**: Mobile-first design that works seamlessly across all devices
- **Smooth Animations**: Scroll-triggered animations, typing effects, and micro-interactions
- **Interactive Projects**: Filterable project gallery with categories (All, Flutter, Full-Stack, AI, Mobile)
- **Dynamic Content**: Animated skill bars, counters, and parallax effects
- **Contact Form**: Direct email integration for easy communication
- **SEO Optimized**: Proper meta tags, semantic HTML5, and accessibility features

---

## 🛠 Technologies Used

- **HTML5**: Semantic markup for better SEO
- **CSS3**: Modern design with CSS Grid, Flexbox, and custom properties
- **JavaScript**: Vanilla JS for interactivity and animations
- **Font Awesome**: Icon library for beautiful icons
- **Google Fonts**: Inter font family for modern typography

## 🚀 Getting Started

### View Locally

Open `index.html` directly in your browser — no build step required.

Or use a local dev server:

```bash
# Python 3
python -m http.server 8000

# PHP
php -S localhost:8000

# Node.js
npx http-server
```

Then open `http://localhost:8000`.

## 🎨 Customization

### Update Profile Information

1. **Personal Details**: Edit the hero section in `index.html`
2. **Skills**: Modify the skills section with your technologies
3. **Experience**: Update the timeline with your work history
4. **Projects**: Add/remove project cards in the projects section
5. **Colors**: Customize the color scheme in `styles.css` (`:root` variables)

### Replace Images

- Profile photo: `assets/images/profile.jpg` (recommended: 500×500px)
- Project screenshots: `assets/images/project-*.png` (recommended: 400×250px)

### Update Contact Links

- GitHub, LinkedIn, Email — update the `href` values in `index.html`
